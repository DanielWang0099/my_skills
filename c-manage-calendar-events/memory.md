# Daniel Preferences Memory

Purpose: store only stable, explicitly confirmed preferences and life context that help with calendar planning.

## Confirmed preferences

- Default planning timezone: Asia/Shanghai (UTC+8); Singapore time/GMT+8 is commonly used.
- Prefers proactive, secretary-style calendar support: check the full affected date range, surface conflicts, and clearly distinguish proposals from actual writes.
- Prefers timing suggestions to account for existing commitments, reasonable buffers, and relevant meal or eating preferences.
- Wants eating and meal breaks considered when planning a day, when they are requested or otherwise explicitly designated as protected time.

## Boundaries

- Do not store events, contacts, meeting links, credentials, message transcripts, temporary availability, or inferred preferences here.
- Add or change an item only when Daniel explicitly asks to remember or save that preference or life detail.
